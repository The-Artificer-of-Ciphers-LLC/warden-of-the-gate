One live shadow review, start to finish

A maintainer starts a manual scan; Warden picks up one pull request, a local model reviews it read-only, Warden checks the result, and the maintainer sees a draft decision card. Nothing is posted to the pull request.

Question this answers. Is the thinnest useful MVP slice, a single read-only review run against one real pull request, well-defined? Which gates stop it, what survives a failure, and when is the model never called at all? Assumption: this slice sits between the plan's P2 and P3 (local Review in shadow mode); the plan has no such milestone yet.
