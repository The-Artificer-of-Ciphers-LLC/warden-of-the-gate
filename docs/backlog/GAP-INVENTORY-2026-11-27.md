## How to read the tables

STATUS values, exactly: `done and tested` / `implemented but not live-verified` / `partial` / `not started` / `blocked by owner/GitHub gate` / `superseded by a later ruling` / `UNKNOWN`.

- `done and tested`: the implementing code and at least one test that exercises it were opened, and the test passes. Most tests run against the in-memory simulated GitHub (`FakeWorld`). Where the behavior's value depends on real GitHub or an Actions runner and no live run exists, the row says `implemented but not live-verified` instead.
- Test references use `file:line` of the `test(...)` declaration under `packages/warden/test/`. Source references are under `packages/warden/src/`.
- "Not opened" notes name what was not verified. A row never claims more than the evidence column shows.
