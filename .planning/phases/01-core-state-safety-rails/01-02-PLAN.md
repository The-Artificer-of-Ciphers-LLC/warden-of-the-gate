<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| GitHub comments → ledger decoder | anyone can post a comment containing the marker |
| keychain → runner | the App private key crosses into process memory |
| config on default branch → runner | maintainer-controlled file drives every label write |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Spoofing | ledger/trust.ts | high | mitigate | numeric user.id + type Bot + performed_via_github_app.id; untrusted → needs-human |
| T-01-04 | Elevation | app-auth.ts mintWrite | high | mitigate | write token minted only in the reconcile verb path; read token has no write perms; static import test in 01-05 |
| T-01-05 | Information disclosure | keychain.ts, logs | high | mitigate | key never logged; errors print `app-key-missing` only |
| T-01-06 | Tampering | fetchRepoConfig | medium | mitigate | config read from default branch via contents API, never from a PR ref or checkout |
</threat_model>
